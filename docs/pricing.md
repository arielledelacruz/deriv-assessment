# Plans and pricing

The Example Developer Platform has Starter, Growth, and Enterprise plans. Starter costs $29 per workspace per month and includes one production project. Growth costs $99 per workspace per month and includes up to five production projects. Enterprise pricing is arranged with the sales team.

There is no free plan. A no-cost sandbox workspace is available for testing and does not include production access. Plan changes take effect at the start of the next billing period. The knowledge base does not specify discounts for startups.
